# Daily Tasks Android

Aplicación Android para organizar tareas diarias. El proyecto está desarrollado con Kotlin y Jetpack Compose.

## Tecnologías

- Kotlin
- Android Jetpack Compose
- Navigation Compose
- Retrofit y Gson para comunicación con API
- Google Sign-In

## Requisitos

- Android Studio con soporte para Kotlin y Jetpack Compose
- Android SDK configurado según el proyecto

## Ejecutar

1. Clona el repositorio y ábrelo en Android Studio.
2. Espera a que Gradle sincronice las dependencias.
3. Ejecuta la configuración `app` en un emulador o dispositivo Android.

También puedes compilar desde la raíz del proyecto:

```bash
# macOS / Linux
./gradlew assembleDebug

# Windows
gradlew.bat assembleDebug
```

La integración con servicios externos puede requerir configuración adicional de credenciales o endpoints antes de usar todas las funciones.
